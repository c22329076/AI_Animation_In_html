Payload / HTTP

02

傳輸層封裝

Layer 4 / TCP

作業系統加上 TCP 頭。關鍵是連接埠號，它標記了哪個程式在通訊。資料流依然是可見的。
Ports
443 → 1024
03

網路層定址

Layer 3 / IP

加上 IP 頭部。這包含真實的源 IP 地址。在普通模式下，這就是資料包的最終外殼。
Source IP

04

IPsec 攔截

ESP / Encryption

策略引擎強行攔截資料包。ESP 協議對內部載荷進行高強度加密。此刻起，中間人徹底致盲。
Security
AES-256 ENCRYPTED
05

隧道新頭部

New IP / Gateway

為了隱藏內部拓撲，生成一個全新的外層 IP。通常是 VPN 閘道器地址。原資料包被整體包裹在內。
Tunnel Source
203.0.113.1
