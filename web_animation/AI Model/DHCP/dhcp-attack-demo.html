攻擊原理拆解

DHCP欺騙攻擊：偷資料的“假伺服器”

  1. 攻擊者連入宿舍WiFi，啟動惡意DHCP服務（如Kali的dnsmasq）
  2. 舍友裝置發DHCP Discover請求時，攻擊者優先傳送虛假Offer（比合法伺服器快）
  3. 舍友裝置“先到先得”，使用假閘道器、假DNS配置
  4. 所有流量先經過攻擊者裝置，用Burp Suite抓包竊取資料，甚至篡改HTTP內容！

DHCP泛洪攻擊：佔IP的“洪水”

  1. 攻擊者用dhcpstarv/hping3工具，偽造海量虛假裝置請求（篡改MAC/Client ID）
  2. 每秒傳送1000+ DHCP Discover包，騙走伺服器所有IP
  3. 合法裝置連網時，伺服器無IP可分配，提示“無有效IP配置”
  4. 伺服器CPU飆升、負載過載，甚至直接宕機，全樓斷網！

如何防住？看完就能用！

個人使用者防禦

  • 手動配置靜態IP：先自動獲取查合法閘道器/子網掩碼，再改“手動”填入，繞過DHCP欺騙
  • 指定公共DNS：阿里雲(223.5.5.5)、騰訊雲(119.29.29.29)，避免DNS劫持
  • 認準HTTPS：所有轉賬、登入操作，必須用“https://”開頭網站，防資料竊取

企業/宿舍管理員防禦

  • 打開DHCP Snooping：交換機區分“信任連接埠”（連合法伺服器）和“非信任連接埠”（攔惡意Offer）
  • 防泛洪配置：限制介面最大MAC學習數，攔截海量虛假請求（如新華三“防餓死攻擊”）
  • 連接埠過濾：僅允許UDP 67/68連接埠合法報文透過，阻斷攻擊流量
